VinculaPro

VinculaPro é um programa criado para automatizar o vínculo de motoristas, veículos e documentos no portal da Usiminas, de forma rápida, segura e sem dor de cabeça.

Ele foi feito para quem trabalha com logística, transporte e operações repetitivas e não quer perder tempo fazendo tudo manualmente.
Qual é o objetivo do VinculaPro ?

Simplificar tarefas que normalmente são:
•	Repetitivas
•	Manuais
•	Lentas
•	Sujeitas a erro humano

Com o VinculaPro, você ganha tempo, reduz erros e padroniza o processo.

	O que o programa faz?

De forma simples:
•	Acessa o portal da Usiminas automaticamente
•	Preenche dados de:
o	Motorista
o	Veículo (cavalo e carreta)
o	Documentos
o	Executa o vínculo sem você precisar clicar em tudo
o	Trabalha com base de dados local
o	Usa licença de ativação para controle de uso

Tudo isso com interface gráfica, sem precisar saber programação.

	Preciso saber programar para usar?
Não.
O programa foi feito para qualquer pessoa usar:

•	Basta abrir
•	Inserir os dados
•	Clicar no botão
•	Pronto

	Sistema de licença

O VinculaPro utiliza um sistema de licença para ativação:
•	A licença tem data de validade
•	Pode ou não ser vinculada ao computador
•	Os dados da licença ficam criptografados (protegidos)
•	O usuário não precisa mexer em arquivos internos
•	Isso garante:
•	Segurança
•	Controle de uso
•	Profissionalismo
